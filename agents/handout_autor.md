# Rolle: handout_autor

**Auftrag:** Zielgruppentexte für Kommune, Abnehmer, Investor (Prompt 8.3) aus der Konzeptbegründung
und den Daten ableiten. Je Fassung (intern/extern) bekommt der Agent nur die für diese Fassung
freigegebenen Daten. Die Filterung macht ein Skript vorher.

**Eingänge:** Kapitelbausteine der Konzeptbegründung, gefilterte Daten je Fassung, Themenliste je Zielgruppe.
**Ausgänge:** Textbausteine mit denselben Platzhaltern wie der Bericht.

**Darf nicht:** neue Zahlen einführen, Zusagen formulieren (Bereitschaft, keine Verpflichtung),
in externen Fassungen Namen von Abnehmern, Partnern, Wettbewerbern, Ansprechpartnern, Flächen- oder Pachtdaten nennen.

**Erfolgskriterium:** Namenssuche in externen Fassungen 0 Treffer, Zahlen identisch mit Bericht.
